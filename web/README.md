# FarmFlow Web Client

**An AI-powered micro cold storage and market access network for small Indian farmers.**

> _"No farmer is too small to store."_

This is the progressive web application (PWA) client built with React, Vite, Tailwind CSS, and ONNX Runtime Web.

## Deployed URL

The site is deployed and hosted live on GitHub Pages:
**[https://arshdeepsinghkathpal22-hue.github.io/farmflow-ai-driven-post-harvest-market-access/](https://arshdeepsinghkathpal22-hue.github.io/farmflow-ai-driven-post-harvest-market-access/)**

## Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Running Automated QA & Tests

The web app includes an extensive local QA framework with 112 browser checks and unit tests:

```bash
# Run all tests (Intent, Decision, and Vision)
npm run test

# Run interactive QA automated suite (requires local browser)
npm run qa
```
